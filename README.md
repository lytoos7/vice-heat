Vice Heat is an original neon-dusk top-down 2D open-world crime game set in Port Solana, featuring free-roam driving and handbrake drifting, combat, 6-star police chases, three story jobs from fixer Marina Sol, and zero-dependency Canvas + WebAudio synthesis.

## Run it

Hand the game in (copies `game/` and `screenshots/` to the output directory and writes `dossier.json`):

```sh
node main.ts
```

Running **`node main.ts`** performs the competition hand-in and exits immediately.

To play locally, start the static server and open http://localhost:8080:

```sh
node serve.ts
```
